# 介護シフト作成システム 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
介護シフト作成システム（bluelamp-vscode1）

### 1.2 目的
介護施設におけるスタッフのシフト管理を効率化し、適切な人員配置を実現するシステムを開発する。

### 1.3 背景
- 介護現場では複雑なシフト管理が必要
- 手作業でのシフト作成は時間がかかり、ミスが発生しやすい
- スタッフの希望や資格、労働規制を考慮した最適なシフト作成が求められる

---

## 2. システム要件

### 2.1 機能要件

#### 2.1.1 スタッフ管理
| 機能 | 説明 | 優先度 |
|------|------|--------|
| スタッフ登録 | 名前、資格、雇用形態、連絡先の登録 | 高 |
| 資格管理 | 介護福祉士、ヘルパー等の資格情報管理 | 高 |
| 勤務可能時間設定 | スタッフごとの勤務可能曜日・時間の設定 | 高 |
| スタッフ一覧表示 | 登録済みスタッフの一覧・検索 | 中 |

#### 2.1.2 シフト作成
| 機能 | 説明 | 優先度 |
|------|------|--------|
| 月間シフト作成 | 月単位でのシフト表作成 | 高 |
| 自動シフト生成 | 条件に基づく自動シフト割り当て | 高 |
| 手動調整 | ドラッグ&ドロップでのシフト編集 | 高 |
| シフトパターン登録 | 早番・日勤・遅番・夜勤等のパターン管理 | 中 |
| 希望シフト入力 | スタッフからの希望シフト収集 | 中 |

#### 2.1.3 制約条件管理
| 機能 | 説明 | 優先度 |
|------|------|--------|
| 最低人員設定 | 時間帯ごとの必要人員数の設定 | 高 |
| 連勤制限 | 連続勤務日数の上限設定 | 高 |
| 夜勤回数制限 | 月間夜勤回数の上限設定 | 高 |
| 休日確保 | 週休・月休の最低日数設定 | 高 |
| 資格要件 | 時間帯ごとの必要資格者数設定 | 中 |

#### 2.1.4 出力・共有
| 機能 | 説明 | 優先度 |
|------|------|--------|
| シフト表印刷 | PDF形式でのシフト表出力 | 高 |
| Excel出力 | Excel形式でのエクスポート | 中 |
| 個人シフト通知 | スタッフへの個別シフト通知 | 中 |

#### 2.1.5 レポート・分析
| 機能 | 説明 | 優先度 |
|------|------|--------|
| 勤務時間集計 | スタッフごとの月間勤務時間表示 | 中 |
| 人件費概算 | 時給に基づく人件費概算 | 低 |

### 2.2 非機能要件

#### 2.2.1 ユーザビリティ
- 直感的なUI/UXデザイン
- レスポンシブデザイン（PC・タブレット対応）
- 操作ガイド・ヘルプ機能

#### 2.2.2 パフォーマンス
- シフト表の表示：3秒以内
- 自動シフト生成：30秒以内（30名規模）

#### 2.2.3 セキュリティ
- ユーザー認証機能
- アクセス権限管理（管理者・一般スタッフ）
- データの暗号化

#### 2.2.4 可用性
- データのバックアップ機能
- オフライン時の基本操作対応

## 5. データモデル（概要）

### 5.1 主要エンティティ
- **Staff（スタッフ）**: スタッフ基本情報
- **Qualification（資格）**: 資格マスタ
- **ShiftPattern（シフトパターン）**: 早番・遅番等のパターン
- **Shift（シフト）**: 実際のシフト割り当て
- **ShiftRequest（希望シフト）**: スタッフからの希望
- **Constraint（制約条件）**: シフト作成時の制約

## 7. 用語定義

| 用語 | 定義 |
|------|------|
| 早番 | 朝から昼過ぎまでの勤務（例：7:00-16:00） |
| 日勤 | 日中の勤務（例：9:00-18:00） |
| 遅番 | 昼過ぎから夜までの勤務（例：12:00-21:00） |
| 夜勤 | 夜から翌朝までの勤務（例：21:00-7:00） |
| 公休 | 所定の休日 |
| 有休 | 有給休暇 |

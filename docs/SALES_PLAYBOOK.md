## 2. 電話トークスクリプト

### 目的
- 施設長（決裁者）との接点を作る
- 15分のオンラインデモを約束する
- 無理な売り込みはしない

### スクリプト

#### 受付突破

```
お忙しいところ恐れ入ります。
介護施設向けのシフト管理システム「CareShift」と申します。

シフト作成のご担当者様、または施設長様はいらっしゃいますでしょうか？
```

#### 担当者と繋がった場合

```
お忙しいところ恐れ入ります。
介護施設専門のシフト管理システム「CareShift」の○○と申します。

突然のお電話で申し訳ございません。
1分だけお時間よろしいでしょうか？

（了承を得たら）

ありがとうございます。
毎月のシフト表、Excel や紙で作られていますか？

（Yesの場合）
多くの施設様で「毎月10時間以上かかる」「夜勤の偏りが出る」と
お悩みを伺っています。

CareShiftは、ボタン1つでシフト表を自動生成できるシステムです。
人員配置基準のチェックも自動で行います。

もしよろしければ、画面を見ていただくのが一番早いのですが、
15分ほどのオンラインデモをご都合のよい日にいかがでしょうか？

もちろん、デモを見たからといって契約の義務はございません。
14日間の無料トライアルもございます。
```

#### よくある断り文句への対応

| 断り | 対応 |
|------|------|
| 「今は忙しい」 | 「失礼しました。いつ頃でしたらお時間いただけますか？改めてご連絡します」 |
| 「シフトは困ってない」 | 「承知しました。もしお知り合いの施設で困っている方がいらっしゃれば、ご紹介いただけますと幸いです」 |
| 「予算がない」 | 「ICT補助金を使えば実質負担を大幅に軽減できます。補助金の情報だけでもお送りしましょうか？」 |
| 「検討中のツールがある」 | 「ちなみにどちらのツールですか？CareShiftはスタッフ数無制限で月9,800円なので、比較資料をお送りすることもできます」 |

#### クロージング

```
ありがとうございます。
では、○月○日○時にオンラインでお会いしましょう。
事前にURLをメールでお送りいたします。

メールアドレスをお伺いしてもよろしいでしょうか？
```

## 3. 直接訪問チェックリスト

### 訪問前の準備
- [ ] 施設の基本情報を調べる（定員数、サービス種別、運営法人）
- [ ] Googleマップで場所・駐車場を確認
- [ ] 名刺を用意（なければ自己紹介カード）
- [ ] ノートPC or タブレットにデモ画面を準備（オフラインでも見せられるよう）
- [ ] 配布用チラシ（FAX DMと同内容をA4カラー印刷）
- [ ] 訪問時間：10:00〜11:00 or 14:00〜15:00（食事・入浴介助の時間を避ける）

### 訪問時のヒアリング項目

#### 基本情報
- [ ] 施設種別（特養 / 老健 / グループホーム / デイ / 有料老人ホーム）
- [ ] スタッフ数（常勤 / パート / 派遣の内訳）
- [ ] 現在のシフト作成方法（Excel / 紙 / 他ソフト）
- [ ] シフト作成の担当者（施設長 / 事務員 / 主任）

#### 課題の深堀り
- [ ] シフト作成にかかる時間は？（月何時間？）
- [ ] 一番大変なことは？（調整？ルール遵守？希望休？）
- [ ] 過去にIT ツールを導入したことはあるか？（成功 / 失敗体験）
- [ ] ICT補助金を使ったことはあるか？

#### 決裁プロセス
- [ ] ツール導入の決裁者は誰か？（施設長 / 法人本部 / 理事会）
- [ ] 予算感の確認（月1万円は許容範囲か？）
- [ ] 導入までにどのくらい期間が必要か？

### 訪問後のアクション
- [ ] お礼メールを当日中に送信
- [ ] ヒアリング内容をパイプラインに記録
- [ ] 次のアクション（デモ日程調整 / 資料送付 / 再訪問）を設定

## 4. パイプライン管理

### ステージ定義

| ステージ | 定義 | 次のアクション |
|----------|------|---------------|
| 1. コンタクト | メール/FAX/電話でアプローチ済み | 反応待ち or フォローアップ |
| 2. 関心あり | 返信 / 電話で話した / 資料請求 | デモ日程の調整 |
| 3. デモ済み | オンラインデモ or 訪問で説明 | トライアル開始の提案 |
| 4. トライアル中 | 14日間の無料トライアル利用中 | 初期設定サポート + 活用状況確認 |
| 5. 商談中 | トライアル後、有料契約を検討中 | 見積もり / 補助金案内 |
| 6. 契約 | 有料契約完了 | オンボーディング |
| ✕ 失注 | 断られた / 反応なし | 3ヶ月後に再アプローチ |

### 管理項目（Googleスプレッドシートで管理）

| 列 | 内容 |
|----|------|
| 施設名 | 正式名称 |
| 施設種別 | 特養 / 老健 / GH / デイ / 有料 |
| 担当者名 | 施設長 or シフト担当者 |
| 電話番号 | - |
| メールアドレス | - |
| ステージ | 1〜6 or ✕ |
| 最終接触日 | yyyy/mm/dd |
| 次のアクション | 具体的な次ステップ |
| 次のアクション期限 | yyyy/mm/dd |
| メモ | ヒアリング内容・断りの理由等 |

## 5. 優先アクション（今週中）

### やること

1. **近隣5施設をリストアップ**（車/電車で30分以内）
   - 定員30名以上の特養 or 老健を優先（スタッフ数が多い = 課題が大きい）
   - Googleマップで「特別養護老人ホーム」「介護老人保健施設」で検索

2. **電話してアポイントを取る**
   - 目標: 5件電話 → 2件アポ → 1件デモ
   - 電話の時間帯: 10:00〜11:00 or 14:00〜15:00

3. **FAX DMを送る**（電話が繋がらなかった施設）
   - コンビニFAX or ネットFAXサービスを利用
   - 送信後 2〜3日で電話フォロー

4. **新メールテンプレで再アプローチ**
   - 既存リストから「メールなし」以外の未反応施設に v2 テンプレで送信
   - 送信上限: 1日30件まで（Resend無料枠）

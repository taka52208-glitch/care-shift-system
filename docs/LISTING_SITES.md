# SaaS比較サイト掲載申請リスト

## 優先度順

### 1. ASPIC（最優先 - 無料開始）
- **申請URL**: https://www.aspicjapan.org/asu/order
- **費用**: 初期0円 / 月額0円 / 成果報酬 1件11,000円（税込）
- **流れ**: 問い合わせ → Zoomインタビュー → 記事作成（全部無料）→ 掲載開始
- **備考**: 医療・介護カテゴリあり。インタビュー記事を無料作成してくれる
- **ステータス**: [ ] 未申請

### 2. ITreview（無料プランあり）
- **申請URL**: https://vendor.itreview.jp/free_plan
- **費用**: 無料プラン0円（基本情報・ロゴ掲載）
- **流れ**: フォーム登録 → 数営業日で公開
- **備考**: 口コミ型。有料プランは初期10万+月額で高額なので無料プランから
- **ステータス**: [ ] 未申請

### 3. 介護のコミミ（介護特化）
- **申請URL**: https://comimi.jp/for_maker
- **費用**: 成果報酬型（詳細要確認）
- **流れ**: 申請済み → 返信待ち
- **備考**: 介護ソフト専門比較サイト。ターゲット完全一致
- **ステータス**: [x] 申請済み（返信待ち → 未返信なら再送）

### 4. ITトレンド（低コスト成果報酬）
- **申請URL**: https://it-trend.jp/help/advertisement
- **費用**: 初期30,000円 / 月額0円 / 成果報酬 1件12,000円
- **流れ**: フォーム申請 → 打ち合わせ → 掲載開始
- **備考**: 掲載製品2,141件。初期費用は必要だが月額なし
- **ステータス**: [ ] 未申請

### 5. BOXIL（要見積もり）
- **申請URL**: https://boxil.smartcamp.co.jp/boxil-ads
- **費用**: 非公開（問い合わせ後に提示）
- **備考**: 月間PV 1,100万。料金が高い可能性あるため見積もり確認後に判断
- **ステータス**: [ ] 未申請

### ❌ PRONIアイミツ SaaS（非推奨）
- 月額30,000〜100,000円 + 契約1年縛り → 初期顧客獲得段階ではコスト高すぎ

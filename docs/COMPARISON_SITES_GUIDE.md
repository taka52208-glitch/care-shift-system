## 2. ITreview（優先度: 高）

### 概要
- **URL**: https://www.itreview.jp/
- **特徴**: IT製品のレビューサイト。無料で製品ページ作成可能
- **カテゴリ**: 「シフト管理」「介護ソフト」
- **効果**: Google検索で「シフト管理 比較」等で上位表示される

### 登録手順
1. https://www.itreview.jp/vendor にアクセス
2. 「製品を掲載する（無料）」から登録
3. 必要情報:
   - 製品名: CareShift
   - カテゴリ: シフト管理システム
   - 概要: 介護施設専門のシフト自動生成システム
   - URL: https://care-shift-system.vercel.app
   - 料金: 月額9,800円（税込）スタッフ数無制限
   - スクリーンショット: 管理画面のキャプチャ（3〜5枚）
4. 審査後に掲載開始

### 次のアクション
- [ ] ITreviewにベンダー登録
- [ ] 製品ページを作成
- [ ] スクリーンショットを用意（ダッシュボード、シフト表、希望休画面）

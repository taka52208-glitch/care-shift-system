# 介護シフト作成システム 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
介護シフト作成システム（bluelamp-vscode1）

### 1.2 目的
介護施設におけるスタッフのシフト管理を効率化し、適切な人員配置を実現するシステムを開発する。

### 1.3 背景
- 介護現場では複雑なシフト管理が必要
- 手作業でのシフト作成は時間がかかり、ミスが発生しやすい
- スタッフの希望や資格、労働規制を考慮した最適なシフト作成が求められる

## 9. SaaS化拡張要件

### 9.1 拡張概要

- **機能名**: SaaS化（マルチテナント対応・課金機能）
- **目的**: 介護シフト作成システムをネット経由で複数の介護事業所に販売可能にする
- **解決する課題**:
  - 単一事業所専用 → 複数事業所が利用可能に
  - 収益化手段がない → サブスクリプション課金で収益化
- **期待効果**: SaaSビジネスとして介護事業所への販売開始

### 9.3 技術仕様

#### 9.3.1 データベース
- **PostgreSQL**への移行（インメモリ → 永続化）
- **Prisma ORM**によるスキーマ管理
- **マイグレーション**によるスキーマ変更管理

#### 9.3.2 マルチテナント設計
- **方式**: 共有データベース + テナントID方式
- **テナント識別**: サブドメイン（例: facility-a.example.com）
- **データ分離**: 全テーブルにtenant_id列を追加

#### 9.3.3 課金システム
- **決済**: Stripe Checkout（ホスト型決済ページ）
- **管理**: Stripe Customer Portal（顧客セルフサービス）
- **Webhook**: 決済イベントの自動処理
- **料金プラン**: 単一プラン（月額固定）

### 9.4 新規データモデル

```typescript
// テナント（事業所）
interface Tenant {
  id: string;
  name: string;           // 事業所名
  subdomain: string;      // サブドメイン
  stripeCustomerId?: string;
  subscriptionStatus: 'active' | 'canceled' | 'past_due' | 'trialing';
  createdAt: Date;
}

// ユーザー（テナント所属）
interface User {
  id: string;
  tenantId: string;       // 所属テナント
  email: string;
  name: string;
  role: 'admin';          // MVPは管理者のみ
  passwordHash: string;
  createdAt: Date;
}

// サブスクリプション
interface Subscription {
  id: string;
  tenantId: string;
  stripeSubscriptionId: string;
  status: 'active' | 'canceled' | 'past_due';
  currentPeriodEnd: Date;
  createdAt: Date;
}
```

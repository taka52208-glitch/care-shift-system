## 6. 起動方法

```bash
# PostgreSQL起動（WSL2）
sudo service postgresql start

# バックエンド（ポート3001）
cd backend && npm run dev

# フロントエンド（ポート3000）
cd frontend && npm run dev
```

**テストアカウント**: admin@example.com / password123

## 営業メール（コピペ用）

### 件名パターン
1. 【14日間無料】介護シフト作成を自動化しませんか？
2. シフト作成を月10時間→30分に短縮する方法
3. 介護施設専用シフト管理システムのご案内

### 本文

```
〇〇施設 管理者様

突然のご連絡失礼いたします。
介護施設向けシフト管理システム「CareShift」の酒井と申します。

貴施設では、毎月のシフト作成にどのくらいの時間をかけていらっしゃいますか？

多くの施設様から
「毎月10時間以上かかる」
「スタッフの希望調整が大変」
「連勤や夜勤のルールを守るのが難しい」
というお声をいただいております。

CareShiftは、これらの課題を自動化で解決します。

■ 主な機能
・日勤/夜勤の人数配置を考慮した自動生成
・スタッフの希望休を反映
・連続勤務・夜勤回数の制限チェック
・有資格者の配置管理

月額9,800円（税込）
※14日間の無料トライアルあり

```
「お忙しいところ恐れ入ります。
 介護シフト管理システムCareShiftの酒井と申します。

 先日、シフト作成の自動化についてメールをお送りしたのですが、
 ご覧いただけましたでしょうか？

 「ありがとうございます。何かご不明点はございましたか？

  ご興味はございますでしょうか？」

 →見てない場合：
 「失礼いたしました。簡単にご説明させていただきますと、
  毎月のシフト作成を自動化できるシステムでして、
  連勤制限や夜勤回数なども自動でチェックできます。
  14日間無料でお試しいただけるのですが、
  よろしければ資料をお送りしてもよろしいでしょうか？」
